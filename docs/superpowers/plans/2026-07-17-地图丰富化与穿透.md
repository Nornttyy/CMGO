# 地图丰富化 + 子弹穿透 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 三路沙镇加地标/分区/高低差/矮墙拱门装饰，并实现按材质硬度与枪械贯穿等级的子弹穿透系统。

**Architecture:** 地图侧沿用"图纸→对象→builder"管线：新对象类型 `low`(矮墙)、分区配色进 `desertMap.ts`、大型装饰集中到新文件 `townProps.ts`。穿透侧：网格打材质标(`mesh.userData.mat`)，穿透判定为纯函数（新文件 `penetration.ts`），`main.ts` 开枪改为"多命中行走"。

**Tech Stack:** TypeScript + Three.js；测试 `npm run test:fast`；国服枪械数据用 Playwright 读 valm.qq.com。

## Global Constraints

- 布局/美术全部自创；枪械数值(贯穿等级)按国服官方武器库配置，实现时逐把核对。
- 拱门/旗帜/灯串等纯装饰**不注册材质标** → 不参与子弹命中；也不加碰撞。
- 钟楼只建在现有实心格上，不改任何碰撞与对枪线。
- 每个 Task 结束：test:fast 全绿 + tsc 无错 + commit；两块各自结束时截图验证 + push + deploy。

### Task 4: 穿透纯函数（TDD）

**Files:** Create `src/game/weapons/penetration.ts`、`tests/penetration.test.ts`；注册进 `scripts/run-logic-tests.ts`

**Interfaces:** Produces:
```ts
export type Mat = 'plant' | 'wood' | 'low' | 'brick' | 'solid';
export type Pen = 1 | 2 | 3;
export interface HitFace { dist: number; mat: Mat; entering: boolean; objId: number }
export interface ShotResult { stopDist: number | null; factor: number; passDists: number[] }
export const PEN_RULES: Record<Mat, { maxThick: [number,number,number]; keep: [number,number,number] }>;
export function resolveShot(faces: HitFace[], pen: Pen): ShotResult;
```
规则=设计单表格；resolveShot 按 dist 升序走面：entering 面找同 objId 的下一 exiting 面得厚度；超上限/keep=0 → stopDist=该面距离；否则 factor*=keep 记 passDists 继续；走完没停 → stopDist=null(飞到天边)。
- [ ] Step 1 失败测试 ≥10 例：木箱低/中/高穿；矮墙低穿挡停/高穿过；砖1.5m内仅高穿×0.45；5m厚墙高穿也停；plant 全穿；两层木箱连乘 0.8×0.8；exit 面缺失(打进不出)按挡停。
- [ ] Step 2 实现到全绿；commit `feat(穿透): 材质×贯穿等级穿透纯函数`。
