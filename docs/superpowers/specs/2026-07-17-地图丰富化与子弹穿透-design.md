# 设计单：地图丰富化 + 子弹穿透系统

日期：2026-07-17　状态：已和用户确认（四个方向全选：地标分区/高低差/矮墙拱门/穿透系统）

## 背景

三路沙镇布局已上线，但用户反馈"太单一"：全图同款砖墙、平地、无地标。
本设计两大块，按顺序交付：**第一块 地图丰富化**（视觉+玩法加料）→ **第二块 子弹穿透**（新玩法系统）。

## 第一块：地图丰富化

### 1. 分区配色（认路）
- 按物体中心 x 坐标分区：x ≤ -20 → B区（墙色偏青蓝的沙岩）；x ≥ 20 → A区（偏暖橙）；中间原色。
- 实现点：`desertMap.ts` 的 `solid`/`buildWalls` 按区选色；合批机制已按颜色分组，自动适配。

### 2. 地标钟楼（认中路）
- 位置：中庭东侧现有实心填充块上（约格子 c16, r6-8 一带），**只加视觉不改碰撞/对枪线**（那里本来就是实心）。
- 造型：程序化沙岩塔（叠盒）高约 14 米 + 四面钟面（canvas 贴图）+ 小尖顶旗帜。全图可见。

### 3. 高低差
- **A 包点高台**：A 区后场 1.2 米高台（约 7.5×5 米）+ 两级 0.6 米台阶（跳/走上去）；加对应碰撞盒；蛋蛋视作障碍绕行（高台故意做小，不影响公平）。
- **中庭喷泉台基**：中庭中心圆形水池（半掩体，可跳上沿）。说明：原"下沉广场"因地面是整块需大改底层，本版以喷泉+高台替代高低博弈。

### 4. 矮墙半掩体
- 新图纸字母 `-` → 新对象类型 `low`（5×1.2×5 米胸墙，沙岩色）：可蹲藏、可跳上、可架枪。
- 铺设：门厅两翼、A 长道中段、包点边缘，共 4~6 格。
- 蛋蛋寻路自动绕行（1.2 米按现有规则算障碍）。

### 5. 装饰拱门 + 细节
- 三条路的路口上方架**纯视觉**拱门横梁（不加碰撞盒——横梁高 3 米以上玩家跳不到，子弹射线也不加它，见第二块材质注册表——不注册 = 不参与命中）。
- A 市集：遮阳棚（彩色布面+木杆）、旗帜串；B 庭院：棕榈+水井（小碰撞盒）+ 青蓝陶罐；屋顶间灯串。
- 新文件 `src/game/world/townProps.ts`：`buildTownProps(scene, walls, ctx)` 统一放地标/高台/喷泉/拱门/装饰，避免 desertMap.ts 膨胀。

## 第二块：子弹穿透系统

### 材质硬度注册
- 每个可被击中的网格打标：`mesh.userData.mat = 'plant' | 'wood' | 'low' | 'brick' | 'solid'`。
- 对应：装饰植物 / 木箱 / 矮墙 / 砖墙房屋钟楼水井喷泉 / 地面主城墙（打不穿）。
- 未注册 `mat` 的网格（拱门横梁、旗帜等纯装饰）不参与子弹命中。

### 枪的贯穿等级
- `GunDef` 加 `pen: 1 | 2 | 3`（低/中/高），数值来自国服官方武器库 valm.qq.com（实现时逐把核对，用户会复查）。

### 穿透规则（纯函数 + 单元测试）
- 射线取**全部命中面**按距离排序；同一物体的进/出面配对得穿行厚度。
- 每种材质对每档贯穿有：最大可穿厚度 + 伤害保留率。基准表（首版，试玩可调）：

| 材质 | 低穿(1) | 中穿(2) | 高穿(3) |
|------|---------|---------|---------|
| plant | 全穿 ×1.0 | 全穿 ×1.0 | 全穿 ×1.0 |
| wood(≤2m) | ×0.55 | ×0.70 | ×0.80 |
| low(≤2m)  | 不可穿 | ×0.55 | ×0.70 |
| brick(≤1.5m) | 不可穿 | 不可穿 | ×0.45 |
| solid | 不可穿 | 不可穿 | 不可穿 |

- 超过该材质最大可穿厚度 → 挡停（如 5 米厚合并墙体天然打不穿）。
- 多层穿透：保留率连乘；最终打中蛋蛋时爆头/身体判定照常，伤害乘累计保留率。
- 特效：每个穿入面留弹孔，拖尾画到最终停点。
- **公平性 v1**：只有玩家子弹穿透；蛋蛋不隔物打玩家。
- 新文件 `src/game/weapons/penetration.ts`：`resolveShot(hits, pen)` 纯函数（输入命中面序列，输出停点与伤害系数），`tests/penetration.test.ts` 全组合单测。

## 验收标准

1. 截图：A 区暖橙/B 区青蓝分区肉眼可辨；钟楼全图可见；A 高台可跳上并俯视包点；中庭喷泉；三路口拱门；矮墙探头位。
2. 单测：穿透纯函数（材质×等级×厚度×多层 ≥10 例）+ 既有 97 项全绿；`tsc --noEmit` 无错。
3. 无头实测：隔木箱打中蛋蛋（伤害为衰减值）；隔砖墙低穿枪打不中。
4. 帧率与现版相当；发布上线并确认线上包哈希更新。
