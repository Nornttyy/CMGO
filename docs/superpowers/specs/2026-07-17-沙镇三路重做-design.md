# 设计单：沙镇三路大改造（经典爆破布局）

日期：2026-07-17　状态：已和用户确认

## 背景

用户觉得现在的地图（15×14 格起手示例图）太无聊，想要"CS 那个味道"的地图。
**明确约束：不一比一复刻 CS:GO 官方地图**（项目规矩：不直接抄官方地图与素材，避免版权问题；已向用户解释并获同意）。做法是采用 FPS 通用的"三路双包点"玩法套路，布局、比例、名字全部自创。

用户已拍板的三个决定：
1. 直接替换现有地图（不做选图界面）；沙漠小镇画风保留。
2. 不做"掉落摔死"机制（那是给之前"悬空之城"方案的，已放弃该方案）。
3. 保持大晴天氛围（上一次改动）。

## 布局（约 24×22 格，一格 5 米 ≈ 120×110 米）

```
        ┌───── 警家(防守出生, 北) ─────┐
     B 包点          中庭          A 包点
        │             ║             │
     B 隧道          中门           A 长道
   (S形深巷两拐角)  (两道门洞对望)   (≈55米直线狙击道)
        │             ║             │
        └───── 匪家(进攻出生, 南) ─────┘
```

- **A 长道**（东）：宽 2 格、长约 11 格的直线走廊，中段放一个探头箱。
- **中门**（中路）：中庭与南中路之间两道横墙、各留 2 格门洞、门洞对齐 → 形成经典"双门对枪线"。
- **B 隧道**（西）：宽 2 格的高墙深巷，S 形两个 90° 拐角。**开顶设计**（引擎的房子是实心方块、没有可走的屋顶/顶棚；高墙巷子玩法等价，机器人寻路无风险）。
- **双包点**：A 东北、B 西北，各有 2~3 个入口（面向 警家/中庭/对应长道）；包点内摆箱子掩体，A 点一小簇箱子当可跳高台。
- **出生点**：匪家南侧中央（spawnT）、警家北侧中央（spawnC）；两家所有出口放准备阶段光幕。
- 图纸最外圈城墙包死；空余死角用墙/房块填充，不留无意义空地。

## 技术改动

| 文件 | 改动 |
|------|------|
| `src/game/world/mapGrid.ts` | 换成新的三路图纸（ASCII 格子） |
| `src/game/world/mapData.ts` | 图例补 `C`=警家出生点、`=`=光幕（光幕朝向按相邻墙自动判断：左右是墙→横跨走廊；上下是墙→竖跨） |
| `src/game/world/mapData.ts` | `MAP_KEY` v2→v3（防止浏览器里旧编辑器存档顶掉新图） |
| `index.html` | 角标版本文案更新 |
| `src/main.ts` | 菜单展台位置沿用"匪家出生点×0.55"公式，截图不好看再手调 |

不改：画风（沙漠+晴天）、掩体/装饰自动撒、机器人 A*（按墙自适应）、小地图（按墙自动画）、编辑器（继续可用，存到 v3 键）。

## 验收标准

1. 无头截图确认：主菜单构图、A 长道直线视线、中门双门对枪线、B 隧道两个拐角、两包点掩体，画面无破洞/漏缝。
2. 连通性程序校验：从匪家出发可达 警家/A 包点/B 包点；三条路各自独立可走。
3. `npm run test:fast` 42 项全过、`tsc --noEmit` 无错。
4. 帧率与现图相当（几何合并批次机制不变）。
5. 发布上线（push + `npm run deploy`），用户强刷即可玩到。
