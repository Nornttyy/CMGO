# 《爆蛋行动》人机AI升级设计单（蛋蛋新大脑）

> 日期：2026-07-17　｜　阶段：里程碑 3「更聪明的敌人」
>
> **一句话**：给 6 只敌方蛋蛋换上"新大脑"——**真实感知**（视野扇形、听枪声脚步声、有记忆、删掉隔墙开挂）、**真瞄准**（能被走位甩开、有反应时间）、**掩体战术**（躲/探头点射/残血撤退）、**团队配合**（共享情报、最多 2 只正面、1 只绕后）。只换"脑子"，蛋蛋的身体（模型/血量/受击/弹痕/重生）不动。

---

## 1. 这一步做什么 / 不做什么（范围）

**做：**
- **感知系统**：120° 扇形视野 + 视线被墙挡住就看不见（**删除现在的"隔墙知道玩家位置"**）；听觉（枪声/脚步声）；被打立刻回头；记住玩家最后出现位置，跟丢会去搜
- **真瞄准**：用"虚拟准星追踪目标"替换现在的掷骰子命中——玩家横向快速移动能甩开瞄准；站定被越瞄越准；发现玩家后有反应延迟才开第一枪；2~3 发点射节奏
- **掩体战术**：启动时沿木箱/油桶/墙自动生成"掩体点"；交战挑能挡视线的掩体，玩"躲→探头点射→缩回"循环；血量低于阈值撤退到远掩体蹲守
- **团队配合**：一只发现玩家 0.5 秒后全队知道；正面交战名额最多 2 只；多余的蛋 1 只被派去绕后包抄、其余驻守警戒；有队友阵亡全队变谨慎
- **潜行玩法自然产生**：蹲着走无声、消音枪（鬼魅）声音半径小 → 玩家可以潜行偷袭
- 为以上写**纯逻辑自动测试** + 无头浏览器试玩验证

**不做（明确排除）：**
- ❌ **难度分级**（用户明确不要——全体蛋蛋统一一档，按原设想"普通"强度调）
- ❌ 主菜单/设置界面改动（因为没有难度选择了）
- ❌ 蛋蛋换弹动画、语音气泡、队形行军
- ❌ 玩家方队友 AI、回合制/下包 AI（以后里程碑再用这些零件拼）

## 2. 架构（脑子和身体分开）

新增 `src/game/ai/` 下 5 个模块，`eggBots.ts` 退化成"身体"：

| 模块 | 职责 | 比喻 |
|------|------|------|
| `botSenses.ts` | 视野/听觉/受击感知/记忆，输出"我知道玩家在哪吗" | 👀👂🧠 眼睛耳朵记忆 |
| `botAim.ts` | 虚拟准星追踪 + 误差模型 + 开火节奏判定 | 🎯 瞄准的手 |
| `botCover.ts` | 掩体点生成（启动时一次）+ 按威胁挑掩体 | 📦 找箱子躲的小脑 |
| `botSquad.ts` | 全队情报共享、正面名额、绕后指派、谨慎度 | 📻 对讲机/指挥官 |
| `botBrain.ts` | 按优先级决策，输出**意图** `{move, face, fire}` | 🌳 从上往下问的决定树 |
| `eggBots.ts`（改） | 执行意图：移动碰撞/转身/开火特效/血量/弹痕/重生 | 🥚 身体 |

**数据流**：`main.ts`（声音事件 + 玩家位置/速度/蹲跑状态）→ 每只蛋：`senses` 更新 → `squad` 汇总派单 → `brain` 出意图 → 身体执行（碰撞推挤照旧）→ 开火经 `aim` 判定命中 → 回调扣玩家血。

**大脑可测试**：`botBrain` 不直接碰 THREE.js，依赖注入世界接口（`canSee` / `findPath` / `coverPoints` / 声音列表），vitest 里喂假数据就能测。

## 3. 决策优先级（每只蛋每秒想 10 次，从上往下谁先"是"做谁）

```
1️⃣ 死了？        → 等重生（现有逻辑不变）
2️⃣ 残血且有威胁？ → RETREAT 撤到远掩体蹲守（"有威胁"=当前看得见玩家，或 lastKnown 还没过期）
3️⃣ 看得见玩家？   → COMBAT 掩体探头点射 / 无掩体则拉扯走位
4️⃣ 被派绕后？     → FLANK 走侧后路线包抄最后known位置
5️⃣ 记得他在哪？   → HUNT 去最后位置周边搜（8秒忘）
6️⃣ 听到动静？     → INVESTIGATE 走过去张望
7️⃣ 都没有        → PATROL 随机游走（现有逻辑不变）
```

准备阶段（光幕未落，`setCombat(false)`）只走 7️⃣，听觉也关闭——和现在一致。

## 4. 关键数值（集中放一个 tuning 常量区，试玩后好调）

| 参数 | 值 | 说明 |
|------|-----|------|
| 视野角/距离 | 120° / 24m | 背后是盲区，可偷袭 |
| 枪声半径 | 狂怒 30m ｜ 鬼魅 10m | 消音器真的有用 |
| 脚步声半径 | 跑 8m（每 0.35s 一次）｜ 蹲走/站定 0 | 蹲走潜行无声 |
| 听到的位置误差 | ±2m | 听声辨位不精确 |
| 反应时间 | 首见 0.4s ｜ 重新看到 0.25s | 遭遇战玩家有反杀窗口 |
| 开火节奏 | 2~3 发点射，发间 0.18s，点射间歇 0.7s | 总火力和现在相近略强 |
| 每枪伤害 | 13 | 不变 |
| 瞄准误差 | 基础小误差 + 随玩家横向速度增大 + 随距离增大；持续可见 1.5s 内逐渐收敛 | 走位可躲，站桩危险 |
| 命中判定 | 沿(瞄准方向+误差)对玩家胶囊(半径0.4m/高1.7m)几何判定，中途有墙打墙 | 不再是纯概率 |
| 残血阈值 | HP < 35 | 触发撤退 |
| 撤退掩体 | 距玩家 > 14m 且背向玩家方向 | 守株待兔面朝来路 |
| lastKnown 遗忘 | 8s | 搜不到回去巡逻 |
| 正面名额 | 2 只 | 其余绕后/驻守 |
| 绕后点 | 以"正面交战蛋 → 玩家lastKnown"连线为正面，取其侧后方 ~12m 的可达点，A* 过去 | 从正面的反方向进攻 |
| 队友阵亡谨慎 | 躲藏时间+50%、交战距离+4m，持续 20s | 越打越猥琐 |
| 思考频率 | 每蛋 10Hz，帧间轮换 | 保帧率 |

## 5. main.ts 接入（改动很小）

- 玩家开枪 → `eggBots.hearGun(x, z, gunId)`（内部映射枪声半径）
- 玩家跑步 → main 按节奏发脚步声事件（main 知道跑/蹲状态）
- `eggBots.update(dt, playerPos)` 加参数 → `update(dt, playerPos, playerVel, crouched)`
- 现有接口不变：`setCombat` / `setBarrierBoxes` / `shootObject` / `tryMelee` / `setOnHit`

## 6. 错误兜底

- A* 找不到路 → 退回随机游走（现有 `newDest` 兜底保留）
- 找不到能挡视线的掩体 → 开阔地拉扯走位（现在的打法当保底）
- 找不到绕后可达点 → 转为驻守
- 向量归一前判零长度，防 NaN；意图执行仍走 `blocked`/`pushOut`，不会穿墙

## 7. 测试与验收

**自动测试**（纯逻辑，`npm run test:fast`）：
- 视野：正后方不可见；墙挡住不可见；120° 边界
- 听觉：半径内听到/外听不到；蹲走无声；鬼魅 10m 狂怒 30m
- 记忆：8s 未刷新遗忘；被背后打立即获得方向
- 瞄准：误差随横向速度上升；静止 1.5s 收敛；反应时间内不开火
- 掩体：选中点确实阻断 LOS；被队友占用不重复选；残血选远掩体
- 小队：正面名额永不超 2；3 只以上存活且知道位置时必有绕后单；死蛋不广播
- 决策：优先级顺序正确（残血撤退压过交战等）

**手动试玩清单**：蹲走绕背偷袭全程不被发现 ✓ 开狂怒引来远处蛋蛋 ✓ 躲起来后蛋去最后位置搜、8秒后放弃 ✓ 蛋会探头点射并缩回 ✓ 打残的蛋撤退蹲守 ✓ 正面同时最多 2 只、有蛋绕后 ✓ 走位能明显甩枪 ✓ 6 蛋满场 FPS ≥ 60 ✓

**无头验证**：按既有经验用游戏内时间等待、专门开战斗场景验证（不再设和平）。

## 8. 以后能复用什么

回合制/下包 AI（未来里程碑）直接复用：感知、瞄准、掩体、小队派单——只需给 `botBrain` 换一层"任务目标"（去下包点/守包/拆包）。
