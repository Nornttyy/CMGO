## 第一段：盖房机 + B 包点望楼

### 盖房机（新文件 `src/game/world/roomBuilder.ts`）
- `roomBoxes(spec): { box: Box; kind: 'wall'|'lintel'|'sill'|'top'|'slab'|'step'|'parapet' }[]` —— **纯函数**出碰撞盒（可单测），`buildRoom(scene, walls, spec)` 负责渲染+推 walls。
- 规格：墙厚 0.3；门洞宽 1.6 高 2.2（门楣盒 y2.2..墙顶）；窗洞宽 1.4、窗台 0..1.1、窗楣 2.1..墙顶；
- 二楼：楼板 y2.9..3.2（留楼梯口）；女儿墙(护栏) 3.2..4.1；楼梯 7 级×0.5 高×0.75 深（自动上台阶已支持 ≤0.55）。
- 材质标：全部 `brick`（0.3 薄墙 → 高穿枪能打穿，合理刺激）。

### 蛋蛋只认一楼
- `main.ts` 给 EggBots 的墙体列表过滤：`walls.filter(w => w.min.y < 2)` —— 门楣/窗楣/楼板/女儿墙不挡蛋蛋寻路；蛋蛋会走门洞进一楼，不上二楼（楼梯盒挡它，绕行）。

### B 望楼（第一栋）
- 位置约 (-42, -31.5)，7×6 米，两层；门朝南+东，一楼窗朝北；二楼女儿墙俯瞰 B 包点。

### 验收
- 单测：门洞地面可通行、窗台/窗楣挡不挡对、楼梯级差 ≤0.55、楼板留口。
- 无头实测：W 走进门、上楼梯（相机 y>4.4）、二楼俯瞰截图。
- 121+ 全绿、tsc、发布上线。
