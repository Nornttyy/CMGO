# 设计单：第二轮打磨（真台阶高低差 / 修穿模 / 长旗帜 / 模型精细化）

日期：2026-07-17　状态：已和用户确认

## 用户反馈（原话要点）

1. 高低差太不明显——要的是**台阶/斜坡/平台**那种走上去的高低差，不是跳箱子。
2. 很多模型穿模——最严重：**蛋蛋的枪戳穿墙/箱子**、**装饰物互相插着**。
3. 旗帜串太短。
4. 程序化模型不够精细。

## 方案

### 1. 自动上台阶 + 天台/露台
- **引擎**：玩家水平移动被挡时，若挡路碰撞盒顶面比脚底高 ≤0.55m 且头顶有空间 → 自动垫步上去（`STEP_UP=0.55`）。纯逻辑进 `src/game/physics` 或 movement 层，配单元测试。
- **A 包点天台**（A 区后场）：2.4m 平台(约10×6m) + 0.4m 踏步楼梯一段 + 台缘 0.9m 护栏矮墙；碰撞盒全推 `walls`。
- **B 庭院露台**：1.6m 平台 + 斜坡（视觉斜面网格，碰撞用 0.25m 密集小台阶盒，走感顺滑）。
- 蛋蛋不上高台（现有寻路把这些盒子当障碍绕行）；台缘护栏保证高台玩家也要探头。

### 2. 修穿模
- 蛋蛋枪管缩短约 1/3（`eggCharacter` 里的枪网格），且蛋蛋对墙的推开半径 +0.25m（steering pushOut 半径）。
- `scatterInside` 碰撞占位 0.6→0.85、间距 2.2→3.0；`scatterCover` 间距 3→3.5。
- 全图巡场截图逐点复查。

### 3. 旗帜串加长
- 三串小旗改为 20~30m 长的跨街大串（A 市集跨整个广场、B 庭院跨庭院、中庭跨喷泉），旗子 0.55→0.8m，另加匪家前场一串。

### 4. 模型精细化（全部本地 Kenney CC0，记 CREDITS）
- 掩体木箱 → `survival/box-large.glb`/`box.glb`（保留碰撞与 wood 材质标）；
- B 水井 → 保留石筒但加 `survival/barrel.glb` 木桶组合；程序化水井顶棚换精细做法；
- A 市集 → `survival/tent-canvas.glb` 帐篷 + 木桶 + `signpost.glb` 告示牌；
- B 庭院 → `survival/fence.glb` 围栏段；
- 钟楼加窗洞(深色内凹面片)与层线细节。
- 模型尺寸一律"目标高度写死 + 包围盒高度归一"，并加**巨大化保险**（放完测包围盒>14m 就跳过并 console.warn）。

## 验收

1. 无头实测：不按跳键走上 A 天台楼梯与 B 露台斜坡（用 `__player` 位置 y 断言 ≥ 平台高）。
2. 巡场截图：枪不穿墙(找贴墙蛋蛋)、装饰无互插、长旗帜、A 市集/B 庭院新模型、天台俯瞰视角。
3. 113+ 项测试全绿（新增 step-up 单测）、tsc 无错、帧率同级。
4. push + deploy + 线上包哈希确认；CREDITS.md 补素材记录。
